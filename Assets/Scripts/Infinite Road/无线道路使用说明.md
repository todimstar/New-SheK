# RoadManager 使用说明文档

## 功能概述
RoadManager是一个用于创建无限滚动道路的Unity脚本，通过重复利用有限数量的道路预制体实现"无限"场景。适合用于模拟行驶场景、跑酷游戏或需要连续移动环境的任何项目。

## 设置指南

### 准备工作
1. **创建道路预制体**：
   - 设计一段道路模型(建议包含完整的场景元素如建筑、树木等)
   - 确保每段道路能够首尾相连，无明显接缝
   - 将设计好的道路保存为预制体(Prefab)

### 场景设置
1. **创建空物体**：
   - 创建一个空GameObject
   - 重命名为"RoadManager"
   - 添加RoadManager脚本组件

2. **配置参数**：
   - **Road Prefab**: 拖拽您创建的道路预制体
   - **Road Count**: 设置同时存在的道路段数量(建议3-5段)
   - **Road Length**: 设置每段道路的长度(必须与实际预制体长度匹配)
   - **Move Speed**: 设置道路移动速度

3. **放置静止的车辆/角色**：
   - 由于是场景移动而非车辆移动，车辆/角色应该放置在固定位置
   - 通常放在场景前方，面向z轴正方向

## 参数详解

| 参数 | 类型 | 说明 |
|------|------|------|
| Road Prefab | GameObject | 道路段预制体，必须设置 |
| Road Count | int | 同时存在的道路段数量，建议≥3 |
| Road Length | float | 每段道路的实际长度(Unity单位) |
| Move Speed | float | 道路移动速度(单位/秒) |

## 工作原理

1. **初始化**：在Start()中实例化多段道路，首尾相连
2. **持续移动**：所有道路段持续向后移动
3. **循环利用**：当最后一段道路移出视野范围，它会被移到最前方

## 常见问题与解决方案

1. **空引用错误**：确保Road Prefab已正确分配
2. **道路接缝问题**：确保Road Length值与预制体实际长度匹配
3. **性能问题**：如果道路预制体过于复杂，考虑使用LOD系统

## 扩展建议

- 添加障碍物生成系统
- 结合粒子系统增加环境效果(雨、雪、雾等)
- 添加昼夜循环系统改变光照

该脚本设计简洁，易于整合到任何需要无限滚动场景的项目中。
